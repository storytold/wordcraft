# Hebrew interface

> **Last reviewed:** 2026-10-25 · **Last updated:** 2026-10-25 · **Change:** initial Hebrew (`he`) interface registration (`locales/he/wordcraft.tsv` in storytold/craft-i18n) · **Target:** WordCraft 0.11.0

Choose **File › Options › Interface language › עברית**, or follow a Hebrew system display language
(`he-IL`, `he_IL.UTF-8`, or legacy `iw-IL`). The catalog code is `he`; `ui.language` with
`{"value":"he"}` selects it explicitly, and `WORDCRAFT_LANGUAGE=he-IL` does the same for a headless
screenshot or a launch while the preference is `auto`. Document text, command ids, CLI/MCP/control
responses and file paths do not change.

craft-i18n's `locales/he/wordcraft.tsv` and `locales/he/common.tsv` (storytold/craft-i18n) provide
the Hebrew interface translations. They are written from the meaning of the English labels; no
proprietary translation resources were consulted.
