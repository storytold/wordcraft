WordCraft runs on Windows 11, macOS, Linux and FreeBSD, and in a modern web browser.

- Windows builds exist for x64 and Arm (arm64). There are also 32-bit (x86) builds.
- The macOS build is universal: one app for Apple silicon and Intel Macs.
- Linux builds exist for x86_64 and aarch64 (Arm), plus RISC-V (riscv64) packages.
- The web build is a static site you host yourself.

Files and install steps are on [Install WordCraft](../getting-started/install.md).

The interface follows your system language by default. It is available in English, 简体中文, 繁體中文, 日本語, Українська, Español, Português (Brasil), Српски, Srpski (latinica), Polski, Čeština, Eesti, Deutsch, Русский, Türkçe, Italiano, Magyar, Français and Български.
