Click the **File** tab, then **Export**, then the format you want. WordCraft asks where to save the copy.

## Steps

1. Click the **File** tab.
2. Click **Export**. (Click **Print** if you want to print; see below.)
3. Click one of the formats:
   - **PDF document (\*.pdf)**
   - **Word document (\*.docx)**
   - **Word XML Document (\*.xml)**
   - **OpenDocument Text (\*.odt)**
   - **Rich Text Format (\*.rtf)**
   - **Web page (\*.html)**
   - **Markdown (\*.md)**
   - **LaTeX (\*.tex)**
   - **Plain text (\*.txt)**
   - **Page image (\*.png)**
4. Pick a folder and name, then confirm. WordCraft reports "Exported" with the path.

The suggested file name is your document's name with the new ending. Your open document stays as it was.

## Printing

The desktop app prints through a PDF.

1. Click the **File** tab, then **Print**. The page shows a preview of your document.
2. Set **Copies** and choose the **Pages**: **All pages**, **Current page**, **Selected pages** or **Custom range** (for example `1-3, 5`). A second list prints only odd or even pages.
3. Click **Print**. WordCraft makes a PDF in a temporary file and opens it in your default PDF viewer (Preview on macOS).
4. Print from that viewer. Choose the printer, two-sided printing and pages per sheet there.

If no PDF viewer is set up, nothing visible happens apart from a message in the status bar. **Save these pages as PDF…** on the same page saves the chosen pages as a PDF file instead.

## Comments and tracked changes

Tick **Print Markup** on the **Print** page to include comments and tracked changes. PDFs, prints and page images show comments beside each page. Web pages, Markdown and text files get a list of comments at the end.

## PDF details

WordCraft's PDF has real, selectable text, links and bookmarks.
