Open files from the **File** tab with **Open** and **Browse…**. Save with **Save** or **Save As**. WordCraft saves .docx by default.

## Open a document

1. Click the **File** tab.
2. Click **Open**.
3. Click **Browse…** and choose a file. Or click a name under **Recent**.

The file picker offers these types: .docx, .docm, .dotx, .dotm, .doc, .dot, .odt, .rtf, .txt, .md, .html, .htm, .tex and .xml (Word XML). WordCraft opens Word 97-2003 .doc files but does not save them. It saves a .docx instead.

On Linux and FreeBSD, if the system file dialog does not appear, click **Browse in WordCraft…** on the same page to use WordCraft's own file browser.

If your current document has unsaved changes, WordCraft asks **Do you want to save changes to** the document first. Choose **Save**, **Don't Save** or **Cancel**. **Save** is selected when the question appears, so Enter saves. Tab or the arrow keys move to the other buttons.

## Save a document

1. Click the **File** tab.
2. Click **Save** to save under the current name. A new document has no name yet, so **Save** opens the **Save As** page.
3. Click **Save As**, then **Browse…**, to save under a different name or place. The suggested name ends in .docx unless the document was opened from another Word package type, such as .dotx, which keeps its own ending.

To save a copy as PDF or another format, see [Export to PDF and other formats](export-to-pdf.md).

## Open Word files with WordCraft by default

1. Click the **File** tab, then **Options**.
2. Under **General**, click **Make WordCraft the default for Word documents…**.

On Windows 11 this opens **Settings › Default apps**, where you choose WordCraft for .docx and the other types. On Linux and FreeBSD, WordCraft becomes the default for .docx, .doc, .rtf and .odt files and Word templates. On Linux this works with the .deb and .rpm packages, not with the AppImage or the Flatpak. The status bar says whether it worked.

On macOS the button is not shown. Instead, select a document in Finder, choose **File › Get Info**, pick WordCraft under **Open with**, then click **Change All**.

## Add a title and author

1. Click the **File** tab, then **Info**.
2. Type in **Title**, **Subject**, **Author**, **Keywords** or **Category**. Changes go into the document as you type.

The same page shows the number of **Pages**, **Words**, **Paragraphs**, **Sections** and **Comments**, and where the file is saved.
