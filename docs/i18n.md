# Interface languages

WordCraft's interface is available in 28 languages and follows the system language by default.
The translations come from [craft-i18n](https://github.com/storytold/craft-i18n), an optional
build input (see [Quick start](../README.md#quick-start)). Without it, WordCraft builds with an
English interface.

English, 简体中文, 繁體中文, 日本語, Português (Brasil), Español, Українська, Српски / Srpski,
Eesti, Türkçe, Русский, Italiano, Deutsch, Polski, Čeština, Magyar, Français, Български,
Tiếng Việt, 한국어, Svenska, Hrvatski, Nederlands, Dansk, Română, العربية (mirrored), Slovenščina.

Serbian is counted twice, once in Cyrillic and once in Latin script. Which languages also have
spelling and grammar proofing is tracked in [localization-parity.md](localization-parity.md).
For spelling dictionaries, see [spelling-dictionaries.md](spelling-dictionaries.md).
