# Glossary

## Formatting defaults

**Normal template**
The saved defaults every new blank document starts from: styles, theme fonts and colours, and page setup. Changed with Set As Default ("all new documents"); cleared with Reset.
_Avoid_: default template, global defaults, app defaults

**Document defaults**
One document's own base formatting (the text and paragraph formatting every style in that document builds on). Changing them affects only that document.
_Avoid_: default font (ambiguous: say which of the two is meant)

**Set As Default**
The action that applies formatting to the open document; when "all new documents" is chosen, it also copies that formatting into the Normal template.
